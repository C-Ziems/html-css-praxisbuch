Kapitel 63: Den Projektstand mit Git verwalten

Aufgaben und Lösungsvorschläge. Bearbeite jede Aufgabe zuerst selbst in einer eigenen Datei außerhalb des Smart-Home-Projekts und öffne erst dann den Lösungsvorschlag.

Aufgabe 1

Nach einer Änderung an css/druck.css soll nur diese Datei aufgezeichnet werden. Gib die Befehle in sinnvoller Reihenfolge an, einschließlich der Prüfung vor und nach dem Commit.

Lösungsvorschlag anzeigen

git status zeigt zuerst, welche Dateien geändert sind. git diff zeigt die Änderung, git diff --staged die vorgemerkte Auswahl. Nach dem Commit bestätigen git status und git log --oneline den Stand. Die Nachricht benennt die tatsächliche Aufgabe.

Aufgabe 2

Eine Datei wird geändert und mit git add vorgemerkt, danach erneut geändert, und anschließend folgt git commit. Erkläre, welcher Stand im Commit landet.

Lösungsvorschlag anzeigen

Im Commit landet der Stand zum Zeitpunkt von git add. Die zweite Änderung ist nicht vorgemerkt und bleibt im Arbeitsverzeichnis. git status zeigt die Datei deshalb danach weiterhin als geändert an. Soll auch die zweite Änderung in den Commit, merken wir die Datei vor dem Commit erneut mit git add vor.

Ein Lösungsvorschlag ist eine mögliche Lösung. Andere Bezeichnungen, Werte oder Formulierungen können ebenso richtig sein, wenn sie die Aufgabe erfüllen und die Begründung trägt.

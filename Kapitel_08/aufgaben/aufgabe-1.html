Eingabe, Ausgabe und Code

Untersuche den Satz im Inspector: kbd umfasst die ganze Tastenkombination und jede einzelne Taste, samp die Ausgabe des Programms, code die Deklaration und den Dateinamen.

Wir drücken Strg + S, und VS Code zeigt kurz Gespeichert an. Die Regel color: navy; steht in style.css.

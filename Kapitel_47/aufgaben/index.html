Kapitel 47: Container Queries: Komponenten an ihren Platz anpassen

Aufgaben und Lösungsvorschläge. Bearbeite jede Aufgabe zuerst selbst in einer eigenen Datei außerhalb des Smart-Home-Projekts und öffne erst dann den Lösungsvorschlag.

Aufgabe 1

Eine Produktkarte zeigt bei einer Inhaltsbreite unter 20rem das Bild über dem Text, ab 20rem daneben. Schreibe Container und Abfrage.

Lösungsvorschlag anzeigen

Die Karte ist der Container, die Abfrage gestaltet ihren Nachfahren .produktkarte-inhalt.

Beispiel zu Aufgabe 1 im Browser öffnen (Datei aufgabe-1.html in diesem Ordner)

Aufgabe 2

Eine Karte soll sich in einer Container Query auf ihre eigene Breite beziehen. Erkläre, warum das nicht möglich ist, und wie man das löst.

Lösungsvorschlag anzeigen

Eine Container Query gestaltet die Nachfahren eines Containers. Würde ein Element seine eigene Gestaltung von seiner Breite abhängig machen, könnte die geänderte Gestaltung wiederum seine Breite ändern; das ergäbe einen Kreislauf. container-type: inline-size isoliert deshalb die Breite des Containers von seinem Inhalt. Soll sich die Karte selbst ändern, machen wir ein umgebendes Element zum Container oder gestalten, wie in Aufgabe 1, ein inneres Element.

Ein Lösungsvorschlag ist eine mögliche Lösung. Andere Bezeichnungen, Werte oder Formulierungen können ebenso richtig sein, wenn sie die Aufgabe erfüllen und die Begründung trägt.

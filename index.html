Begleitmaterial zum Buch

Im Buch entsteht Kapitel für Kapitel die Website eines virtuellen Smart Homes. Hier findest du den Stand dieses Projekts nach jedem Kapitel, das den Code verändert, und ab Kapitel 6 zu jedem Kapitel die Aufgaben mit Lösungsvorschlägen und lauffähigen Beispielen.

  • Projektstände vergleichen Weicht dein Ergebnis ab, öffne den Projektstand des Kapitels und vergleiche ihn mit deinem Code. Möchtest du einen Stand verändern, arbeite in einer Kopie.
  • Aufgaben zuerst selbst lösen Die Lösungsvorschläge sind zunächst verborgen. Bearbeite jede Aufgabe in einer eigenen Datei und öffne erst dann den Vorschlag.
  • Herunterladen und lokal öffnen Alle Dateien als ZIP herunterladen oder das Repository auf GitHub öffnen. Öffne die Dateien wie im Buch über einen lokalen Webserver, etwa mit Live Server in VS Code.
